# Deepak & Pooja — Pages of Us

A standalone mobile-first wedding invitation website built using the 10 supplied photographs.

## Preview
Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Before publishing
- Confirm event dates, timings, and exact venue details against the existing invitation; this version only states the known wedding date and city.
- Replace the generic Agra map link with the exact venue map URL.
- Replace the placeholder email RSVP with the preferred WhatsApp contact URL (e.g. `https://wa.me/<number>?text=<encoded message>`).
- Check wording and story sequence with the couple; no precise photo dates are asserted.
- Add licensed/authorized background music only after confirming the track and playback rights; use an opt-in play/pause button.

## Deployment
All files are static. Deploy the folder contents to GitHub Pages or any static web host. No build step is required. Fonts load from Google Fonts; fallback fonts work offline.
